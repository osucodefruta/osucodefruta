**Desenvolvedor de jogos web e sistemas** 🎮 Crio RPGs no navegador, SaaS e ferramentas com IA, do protótipo ao produto rodando.

---

## 🚀 Projetos em destaque

### 🏰 Mists of Cracovia
RPG completo em um único arquivo HTML: sistema de áudio, tela de abertura, travas de classe e atalhos de teclado.
`JavaScript` `HTML` `CSS`

### 🕹️ Jogo idle/RPG multiplayer online
Jogo de progressão lenta com caça automática, captura, loja, centro de criação, profissões, chat e cidade multiplayer. Contas e saves no servidor.
`JavaScript` `Node.js` `SQLite` `WebSocket`

### 🎮 JogoPhaser
Jogo 2D feito com Phaser.
`Phaser` `JavaScript`

### 🍹 OndaPOS (SaaS)
Sistema de comandas e caixa para bares e restaurantes: mesas, cardápio, estoque, fechamento por forma de pagamento, relatórios e login separado para dono e garçom. Funciona offline e sincroniza com a nuvem.
`Node.js` `Express` `SQLite` `Electron` `PWA` `Supabase`

### 🛠️ Ferramentas web
- Sugeridor de hunts para Tibia (HTML/CSS/JS, tema RPG com animações CSS)
- Gerador de imagem/vídeo com IA integrando Hugging Face e Replicate
- Sistema próprio de link-in-bio (Node/Express/SQLite)
